## Part 1 — Input Validation

A good program shouldn't blindly accept everything.

For example:

```text
Enter marks: 150
```

❌ Invalid.

Your program should ask again.

### Example

```c
do
{
    printf("Enter marks (0-100): ");
    scanf("%f", &marks);

    if(marks < 0 || marks > 100)
    {
        printf("Invalid marks!\n");
    }

} while(marks < 0 || marks > 100);
```

# Part 2 — Duplicate ID Checking

Suppose:

```text
Student 101 already exists.
```

The program shouldn't allow another student with ID `101`.

Create:

```c
int idExists(struct Student students[], int count, int id);
```

Return:

```text
1 → ID exists
0 → ID doesn't exist
```

Example:

```c
if(idExists(students, count, id))
{
    printf("ID already exists!\n");
}
```

This is a good example of separating **validation logic** from the rest of your program.

# Part 3 — Saving Data to a File

Your program currently loses all students when it closes.

Let's fix that.

Use:

```c
FILE *fp;

fp = fopen("students.dat", "wb");
```

`"wb"` means:

* `w` → write
* `b` → binary

---

## Writing a Structure

```c
fwrite(&student,
       sizeof(struct Student),
       1,
       fp);
```

For multiple students:

```c
fwrite(students,
       sizeof(struct Student),
       count,
       fp);
```

Then:

```c
fclose(fp);
```

---

# Part 4 — Loading Data

Open:

```c
fp = fopen("students.dat", "rb");
```

Then:

```c
count = fread(students,
              sizeof(struct Student),
              capacity,
              fp);
```

Now your program can restore the previous data.

---

# ⚠️ Important Concept

Understand the difference:

```text
students
```

means the address of the first structure.

```text
&students
```

is something different.

For arrays, you need to understand what expression you're passing to `fwrite()` and why.

Don't memorize it.

# 🐛 Debugging Challenge

```c
FILE *fp;

      sizeof(struct Student),
      count,
      fp);

```

### Answer:

1. What happens if `fp == NULL`?
2. Why shouldn't `fread()` execute after a failed `fopen()`?

# 🟡 Session 2 — Aptitude — 40 min

# Topic: Time & Work

This is a high-value placement aptitude topic.

## Basic Concept

If A completes a job in 10 days:

```text
A's 1-day work = 1/10
```

If B completes it in 20 days:

```text
B's 1-day work = 1/20
```

Together:

```text
1/10 + 1/20
= 3/20
```

Therefore:

```text
Time = 20/3 days
```
