# Session 1 – C Programming (100 Minutes)

## Topic

# File Handling (Basics)

### Learn (35 Minutes)

## 1. What is File Handling?

File handling allows programs to **store data permanently** instead of losing it when the program exits.

---

## 2. File Pointer

```c
FILE *fp;
```

`FILE` is a structure defined in `<stdio.h>`.

---

## 3. Opening a File

```c
fp = fopen("student.txt", "w");
```

### File Modes

| Mode   | Purpose                                         |
| ------ | ----------------------------------------------- |
| `"r"`  | Read existing file                              |
| `"w"`  | Write (creates new file or overwrites existing) |
| `"a"`  | Append data at the end                          |
| `"r+"` | Read and write                                  |
| `"w+"` | Read and write (overwrites)                     |
| `"a+"` | Read and append                                 |

---

## 4. Writing to a File

```c
fprintf(fp, "Hello World");
```

---

## 5. Reading from a File

```c
char ch;

while((ch = fgetc(fp)) != EOF)
{
    printf("%c", ch);
}
```

---

## 6. Closing a File

```c
fclose(fp);
```

Always close the file after finishing.

## Debugging Challenge (15 Minutes)

Find and fix the errors.

```c
#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt","r");

    fprintf(fp,"Hello");

    fclose(fp);

    return 0;
}
```

### Questions

1. Why is writing not allowed here?
2. Which file mode should be used?
3. What should you do if `fopen()` returns `NULL`?

# Session 2 – Aptitude (40 Minutes)

## Topic

# Probability (Basics)

### Learn (15 Minutes)

Formula:

```text
Probability = Number of Favourable Outcomes
              ------------------------------
              Total Number of Outcomes
```

Probability is always between **0** and **1**.

---

### Practice (25 Minutes)

1. A coin is tossed once. Find the probability of getting a Head.
2. A die is rolled. Find the probability of getting:

   * 4
   * An even number
3. A bag contains 5 red and 3 blue balls. Find the probability of selecting a blue ball.
4. A card is drawn from a standard deck of 52 cards. Find the probability of drawing:

   * A King
   * A Heart
5. Two coins are tossed. Find the probability of getting exactly one Head.
