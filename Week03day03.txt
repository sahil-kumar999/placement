# 🟢 Session 1 — C Programming (100 minutes)

## Topic 1: Structure Pointers

### 1. Pointer to a Structure

You already know:

```c
struct Student
{
    int roll;
    float marks;
};
```

Create a structure:

```c
struct Student s = {101, 85.5};
```

Create a pointer:

```c
struct Student *p = &s;
```

Access members using:

```c
(*p).roll
(*p).marks
```

But there is a shorter and more commonly used syntax:

```c
p->roll
p->marks
```

### Important

```c
s.roll       // normal structure variable
p->roll      // pointer to structure
```

---

## 2. Example

```c
#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s = {101, 85.5};

    struct Student *p = &s;

    printf("Roll: %d\n", p->roll);
    printf("Marks: %.2f\n", p->marks);

    return 0;
}
```

### Understand this carefully

```text
s       → actual structure
&s      → address of structure
p       → stores address of structure
p->roll → accesses roll through pointer
```

# Topic 2: Dynamic Memory Allocation

Normally:

```c
int arr[10];
```

The size is fixed.

Dynamic memory allows you to request memory **during program execution**.

The main functions are:

| Function    | Purpose                                  |
| ----------- | ---------------------------------------- |
| `malloc()`  | Allocates memory                         |
| `calloc()`  | Allocates and initializes memory to zero |
| `realloc()` | Changes allocated memory size            |
| `free()`    | Releases allocated memory                |

Include:

```c
#include <stdlib.h>
```

---

## 3. `malloc()`

Example:

```c
int *p;

p = malloc(5 * sizeof(int));
```

This requests memory for **5 integers**.

Always check:

```c
if(p == NULL)
{
    printf("Memory allocation failed");
    return 1;
}
```

After using the memory:

```c
free(p);
```

---

## 4. `calloc()`

```c
int *p;

p = calloc(5, sizeof(int));
```

This allocates space for 5 integers and initializes the allocated memory to zero.

---

## 5. `realloc()`

Suppose you initially allocate space for 5 integers:

```c
p = malloc(5 * sizeof(int));
```

Later you need 10:

```c
p = realloc(p, 10 * sizeof(int));
```

---

## 6. `free()`

When you're finished:

```c
free(p);
p = NULL;
```

This prevents you from accidentally using the old pointer.

# 🐛 Debugging Challenge — 15 minutes

Find the problems:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *p;

    p = malloc(5 * sizeof(int));

    for(int i = 0; i <= 5; i++)
    {
        p[i] = i * 10;
    }

    printf("%d", p[5]);

    return 0;
}
```

Answer these:

1. How many elements were allocated?
2. What is wrong with `i <= 5`?
3. What is wrong with `p[5]`?
4. What important statement is missing at the end?

# 🟡 Session 2 — Aptitude (40 minutes)

# Topic: Profit & Loss — Advanced

## Learn

### Profit

```text
Profit = SP − CP
```

### Loss

```text
Loss = CP − SP
```

### Profit Percentage

```text
Profit % = (Profit / CP) × 100
```

### Loss Percentage

```text
Loss % = (Loss / CP) × 100
```

Where:

* CP = Cost Price
* SP = Selling Price

# 🔵 Session 3 — Logical Reasoning (30 minutes)

# Topic: Ranking & Ordering

Learn these concepts:

* Rank from left
* Rank from right
* Total number of people
* Position between two people

### Important Formula

If a person has:

```text
Rank from left = 8
Rank from right = 12
```

Then:

```text
Total = 8 + 12 − 1
      = 19
```
