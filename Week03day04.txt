## Part 1 — Structure Pointer Revision (15 min)

Consider:

```c
struct Student
{
    int roll;
    char name[50];
    float marks;
};
```

Create a structure:

```c
struct Student s;
```

Create a pointer:

```c
struct Student *p = &s;
```

Access members:

```c
p->roll
p->name
p->marks
```

Remember:

```text
s.roll       → structure variable
p->roll      → structure pointer
```

# Part 2 — Dynamic Array of Structures (25 min)

Suppose you don't know how many students the user will enter.

Instead of:

```c
struct Student students[100];
```

you can dynamically allocate memory:

```c
struct Student *students;

students = malloc(n * sizeof(struct Student));
```

Example:

```c
#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    int n;

    printf("Enter number of students: ");
    scanf("%d", &n);

    struct Student *students;

    students = malloc(n * sizeof(struct Student));

    if(students == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for(int i = 0; i < n; i++)
    {
        printf("\nEnter student %d details\n", i + 1);

        printf("Roll: ");
        scanf("%d", &students[i].roll);

        printf("Name: ");
        scanf(" %49[^\n]", students[i].name);

        printf("Marks: ");
        scanf("%f", &students[i].marks);
    }

    for(int i = 0; i < n; i++)
    {
        printf("\n%d %s %.2f",
               students[i].roll,
               students[i].name,
               students[i].marks);
    }

    free(students);

    return 0;
}
```

### Important

Both of these work:

```c
students[i].marks
```

and:

```c
(students + i)->marks
```

Understand **why** before moving on.

# Part 3 — Structures + File Handling (30 min)

Now we'll permanently store student records.

Example:

```c
FILE *fp;

fp = fopen("students.txt", "w");

if(fp == NULL)
{
    printf("File could not be opened");
    return 1;
}

fprintf(fp, "%d %s %.2f\n",
        s.roll,
        s.name,
        s.marks);

fclose(fp);
```

### Reading records

```c
fp = fopen("students.txt", "r");

while(fscanf(fp, "%d %49s %f",
             &s.roll,
             s.name,
             &s.marks) == 3)
{
    printf("%d %s %.2f\n",
           s.roll,
           s.name,
           s.marks);
}

fclose(fp);
```

For today's first implementation, keep names as **single words** when storing them with `fscanf()`. We'll handle more complex text records later.

# 🟡 Session 2 — Aptitude (40 minutes)

# Topic: Ratio & Proportion

You've already worked with percentages and averages. Today we'll strengthen **ratio reasoning**, which is important for placement aptitude.

## Learn

If:

```text
A : B = 2 : 3
```

then:

```text
A = 2x
B = 3x
```

### Example

If the ratio of boys to girls is:

```text
3 : 2
```

and there are 30 boys:

```text
3x = 30
x = 10

Girls = 2 × 10
      = 20
```
