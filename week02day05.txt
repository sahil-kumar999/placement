# Session 1 – C Programming (100 Minutes)

## Topic

### Passing Arrays to Functions

### Learn (30 Minutes)

Study these concepts:

### 1. Passing an Array to a Function

Example:

```c
#include <stdio.h>

void printArray(int arr[], int size)
{
    for(int i = 0; i < size; i++)
    {
        printf("%d ", arr[i]);
    }
}

int main()
{
    int a[5] = {10, 20, 30, 40, 50};

    printArray(a, 5);

    return 0;
}
```

---

### 2. Arrays are Passed by Reference

When an array is passed to a function, the function receives the address of the first element.

Example:

```c
void doubleValues(int arr[], int size)
{
    for(int i = 0; i < size; i++)
    {
        arr[i] *= 2;
    }
}
```

Changes made inside the function affect the original array.

# Session 2 – Aptitude (40 Minutes)

## Topic

### Pipes and Cisterns (Basics)

### Learn (15 Minutes)

Key idea:

A pipe filling a tank is **positive work**.

A pipe emptying a tank is **negative work**.

Example:

```text
Pipe A fills a tank in 8 hours.
One hour work = 1/8

Pipe B empties the tank in 12 hours.
One hour work = -1/12

Together:
1/8 - 1/12 = 1/24

Tank fills in 24 hours.
```

---

### Practice (25 Minutes)

1. A pipe fills a tank in **6 hours**. How much of the tank does it fill in one hour?
2. A pipe empties a tank in **10 hours**. What fraction is emptied in one hour?
3. Pipe A fills a tank in **8 hours** and Pipe B fills it in **12 hours**. How long together?
4. Pipe A fills in **9 hours** and Pipe B empties in **18 hours**. How long will it take to fill the tank?
5. A tank is full. One outlet empties it in **20 hours**. How much water remains after **5 hours** if only the outlet is open?
