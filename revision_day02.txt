# 🐛 Debugging Challenge

Find the problem in this program:

```c
#include <stdio.h>

int main()
{
    int n;
    int reverse = 0;

    printf("Enter number: ");
    scanf("%d", &n);

    while(n > 0)
    {
        int remainder = n % 10;
        reverse = reverse * 10 + remainder;
    }

    printf("Reverse = %d", reverse);

    return 0;
}
```

### Your task

Don't just fix it.

Explain **why the program doesn't terminate**.
