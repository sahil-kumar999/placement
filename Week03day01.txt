# Session 1 – C Programming (100 Minutes)

## Topic

# Structures in C (Basics)

### Learn (30 Minutes)

Study these concepts:

### 1. What is a Structure?

A structure is a **user-defined data type** that groups different types of data under one name.

Example:

```c
struct Student
{
    int rollNo;
    char name[50];
    float marks;
};
```

---

### 2. Declaring Structure Variables

```c
struct Student s1;
```

---

### 3. Accessing Members

Use the **dot (`.`) operator**.

```c
s1.rollNo = 101;
strcpy(s1.name, "Rahul");
s1.marks = 89.5;
```

---

### 4. Input and Output

```c
printf("Enter Roll No: ");
scanf("%d", &s1.rollNo);

printf("Enter Name: ");
scanf(" %49[^\n]", s1.name);

printf("Enter Marks: ");
scanf("%f", &s1.marks);
```

---

### 5. Why Use Structures?

Without structures:

```text
rollNo
name
marks
```

are stored separately.

With structures:

```text
Student
 ├── rollNo
 ├── name
 └── marks
```

Everything belongs to one student record.

## Debugging Challenge (20 Minutes)

Find and fix the errors.

```c
#include <stdio.h>

struct Student
{
    int roll;
    char name[20];
};

int main()
{
    struct Student s;

    scanf("%d", s.roll);

    printf("%d", s.roll);

    return 0;
}
```

### Questions

1. Why is `scanf("%d", s.roll);` incorrect?
2. How should it be written?
3. Why is `&` required here?
