## 1. What is CRUD?

CRUD means:

| Operation | Meaning |
| --------- | ------- |
| C         | Create  |
| R         | Read    |
| U         | Update  |
| D         | Delete  |

For our Student Management System:

```text
Create → Add student
Read   → Display students
Update → Modify student
Delete → Remove student
```

These four operations are fundamental to almost every database application.

---

# 2. Create — Add Student

Suppose:

```c
struct Student
{

```

A function could look conceptually like:

```c
void addStudent(struct Student students[], int *count)
{

    // increase count

```

Notice:

```c

```

Why?

Because the function needs to modify the original `count`.

# 4. Search

Start with **Linear Search**.

Example:

```c
int searchStudent(struct Student students[],
                  int count,
                  int id)
{
    for(int i = 0; i < count; i++)
    {
        if(students[i].id == id)
        {
            return i;
        }
    }

    return -1;
}
```

If found:

```text
Index = 2
```

If not:

```text
-1
```

### Important

Understand **why we return the index**, rather than just printing the student.

Returning the index allows another function to:

* update
* delete
* display
* modify

that student.

# 6. Delete

Suppose:

```text
101
102
103
104
```

Delete `102`.

Move:

```text
103 → 102's position
104 → 103's position
```

Then decrease:

```c
count--;
```

This is an important array concept.

# 7. Sorting

Today implement **Bubble Sort**.

Example:

```text
80 50 90 60
```

After sorting:

```text
50 60 80 90
```

Basic logic:

```c
for(int i = 0; i < count - 1; i++)
{
    for(int j = 0; j < count - i - 1; j++)
    {
        if(students[j].marks > students[j + 1].marks)
        {
            // swap
        }
    }
}
```

Don't memorize this.

Understand **why the largest element moves toward the end after each pass**.

# 🐛 Debugging Challenge — 10 min

Find the bug:

```c
void deleteStudent(struct Student students[],
                   int *count,
                   int index)
{
    for(int i = index; i < *count; i++)
    {
        students[i] = students[i + 1];
    }

    (*count)--;
}
```

### Questions

1. What is wrong with the loop condition?
2. Which index can become invalid?

# 🟡 Session 2 — Aptitude (40 minutes)

# Topic: Average

## Basic Formula

```text
Average = Sum of observations / Number of observations
```

### Example

Numbers:

```text
10, 20, 30
```

Average:

```text
60 / 3 = 20
```

---

## Important Shortcut

If the average of 5 numbers is 20:

```text
Total = 5 × 20
      = 100
```
