# 🧪 Part 3 — Testing

Don't just test the **happy path**.

Create a test table:

| Test                    | Expected Result      |
| ----------------------- | -------------------- |
| Add valid student       | Student added        |
| Duplicate ID            | Rejected             |
| Marks = 50              | Accepted             |
| Marks = 101             | Rejected             |

| Search invalid ID       | Not found            |

| Delete existing student | Deleted              |

| Save data               | File created/updated |
| Restart program         | Old data loaded      |

# 🐛 Part 4 — Debugging Challenge

Find all issues:

```c
#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int id;
    char name[50];
    float marks;
};

int main()
{
    struct Student *students;

    int count = 0;

    students = malloc(5 * sizeof(struct Student));

    students[count].id = 101;
    students[count].marks = 85;

    count++;

    free(students);

    printf("%d\n", students[0].id);

    return 0;
}
```

### Questions

**Q1.** Is the memory allocation correct?

**Q2.** What happens when `students[0].id` is accessed after `free()`?

**Q3.** What type of bug is this?

**Q4.** Where should `free(students)` occur?

**Q5.** Should you set the pointer to `NULL` after freeing it?
