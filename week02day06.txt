# Session 1 – C Programming (100 Minutes)

## Topic

### 2D Arrays with Functions

### Learn (30 Minutes)

### 1. Passing a 2D Array to a Function

Example:

```c
#include <stdio.h>

void printMatrix(int a[3][3])
{
    int i, j;

    for(i = 0; i < 3; i++)
    {
        for(j = 0; j < 3; j++)
        {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }
}

int main()
{
    int a[3][3] = {
        {1,2,3},
        {4,5,6},
        {7,8,9}
    };

    printMatrix(a);

    return 0;
}
```

# Session 2 – Aptitude (40 Minutes)

## Topic

### Permutations & Combinations (Introduction)

### Learn (15 Minutes)

### Permutation (Arrangement)

Formula:

```text
ⁿPᵣ = n! / (n − r)!
```

### Combination (Selection)

Formula:

```text
ⁿCᵣ = n! / (r! × (n − r)!)
```

Remember:

* **Permutation → Order matters**
* **Combination → Order does not matter**

---

# Session 3 – Logical Reasoning (30 Minutes)

## Topic

### Data Sufficiency (Basics)

### Learn

Determine whether the given statements are enough to answer the question.

Use this answer format:

* A. Statement I alone is sufficient.
* B. Statement II alone is sufficient.
* C. Both statements together are sufficient.
* D. Neither statement is sufficient.

---

### Practice

### Q1

Question:

> Is x greater than 20?

Statement I:

* x = 25

Statement II:

* x is an even number.

---

### Q2

Question:

> Is y divisible by 5?

Statement I:

* y ends with 0.

Statement II:

* y is divisible by 10.

---

### Q3

Question:

> What is Rahul's age?

Statement I:

* Rahul is older than Aman.

Statement II:

* Aman is 18 years old.

---

### Q4

Question:

> Is a triangle right-angled?

Statement I:

* The sides are 3, 4, and 5.

Statement II:

* One angle is 90°.

---

### Q5

Question:

> Is n an odd number?

Statement I:

* n is divisible by 2.

Statement II:

* n leaves a remainder of 1 when divided by 2.
