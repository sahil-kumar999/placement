# Session 1 – C Programming (100 Minutes)

## Topic

### Pointer Arithmetic & Pointers with Arrays

### Learn (35 Minutes)

## 1. Pointer Arithmetic

Pointers can be incremented and decremented.

```c
int a[] = {10,20,30,40,50};
int *p = a;

printf("%d\n", *p);   // 10

p++;

printf("%d\n", *p);   // 20
```

Remember:

* `p++` moves to the next element.
* `p--` moves to the previous element.
* `p + n` moves forward by `n` elements.
* `p - n` moves backward by `n` elements.

---

## 2. Arrays and Pointers

The array name stores the address of its first element.

```c
int a[5]={10,20,30,40,50};

printf("%d\n", a[0]);
printf("%d\n", *a);

printf("%d\n", a[2]);
printf("%d\n", *(a+2));
```

Notice:

```
a[3]
```

is equivalent to

```
*(a+3)
```

---

## 3. Traversing an Array Using Pointers

```c
int a[5]={2,4,6,8,10};
int *p=a;

for(int i=0;i<5;i++)
{
    printf("%d ",*(p+i));
}
```

# Session 2 – Aptitude (40 Minutes)

## Topic

### Boats and Streams (Basics)

### Learn (15 Minutes)

Important formulas:

```
Downstream Speed
=
Boat Speed + Stream Speed
```

```
Upstream Speed
=
Boat Speed − Stream Speed
```

Where:

* Boat Speed = speed in still water
* Stream Speed = speed of the river

---
