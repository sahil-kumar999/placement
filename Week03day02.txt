# Session 1 – C Programming (100 Minutes)

## Topic

# Nested Structures & Structures with Functions

## Learn (35 Minutes)

### 1. Nested Structures

A structure can contain another structure.

Example:

```c
#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int rollNo;
    char name[50];
    struct Date dob;
};

int main()
{
    struct Student s;

    s.rollNo = 101;
    s.dob.day = 15;
    s.dob.month = 8;
    s.dob.year = 2006;

    printf("DOB: %02d/%02d/%d", s.dob.day, s.dob.month, s.dob.year);

    return 0;
}
```

---

### 2. Passing Structures to Functions

Example:

```c
#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

void display(struct Student s)
{
    printf("Roll: %d\n", s.roll);
    printf("Marks: %.2f\n", s.marks);
}

int main()
{
    struct Student s = {101, 88.5};

    display(s);

    return 0;
}
```

---

### 3. Returning a Structure from a Function

Example:

```c
#include <stdio.h>

struct Student
{
    int roll;
};

struct Student createStudent()
{
    struct Student s;
    s.roll = 101;
    return s;
}

int main()
{
    struct Student s = createStudent();
    printf("%d", s.roll);

    return 0;
}
```

## Debugging Challenge (15 Minutes)

Find and fix the errors.

```c
#include <stdio.h>

struct Student
{
    int roll;
};

void display(struct Student *s)
{
    printf("%d", s.roll);
}

int main()
{
    struct Student st = {101};

    display(&st);

    return 0;
}
```

### Questions

1. Why is `s.roll` incorrect?
2. Which operator should be used?
3. Rewrite the corrected function.
