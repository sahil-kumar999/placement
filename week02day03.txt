# Session 1 – C Programming (100 Minutes)

## Topic

### Introduction to Pointers

### Learn (35 Minutes)

Study these concepts carefully:

### 1. What is a Pointer?

A pointer is a variable that stores the **address** of another variable.

Example:

```c
int a = 10;
int *p = &a;
```

Here:

* `a` stores the value `10`
* `&a` gives the memory address of `a`
* `p` stores the address of `a`
* `*p` gives the value stored at that address (`10`)

---

### 2. Operators

* `&` → Address-of operator
* `*` → Dereference operator

Example:

```c
int a = 25;
int *p = &a;

printf("%d\n", a);
printf("%p\n", (void*)&a);
printf("%p\n", (void*)p);
printf("%d\n", *p);
```

---

### 3. Pointer Declaration

```c
int *ptr;
float *fptr;
char *cptr;
```

---

### 4. Pointer and Variable Relationship

If:

```c
int x = 50;
int *ptr = &x;
```

Then:

* `x` = 50
* `&x` = address of x
* `ptr` = address of x
* `*ptr` = 50

### Learn

