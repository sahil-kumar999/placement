**10 marks**

### Q6. — 2 marks

```c
#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s = {101, 85.5};

    struct Student *p = &s;

    printf("%d %.1f", p->roll, p->marks);

    return 0;
}
```

What is the output?
